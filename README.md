## How I build

- **Agents with contracts.** Strict output schemas, defensive parsing of model output and fallbacks, so an LLM is a dependable component rather than a demo.
- **Product first.** Start from the user's actual pain, ship a working slice early, then iterate on evidence.
- **Engineering hygiene.** No secrets in code, READMEs a stranger can follow, and CI so the build stays green.
